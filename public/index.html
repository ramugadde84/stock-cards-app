Live merchant lookup is off — what it would take to turn on

There is no free public API of working promo codes. The only legitimate source is an affiliate network, where merchants publish their own current offers with real start/end dates. That needs a publisher account:

  1. Register as a publisher with Rakuten Advertising. It's a real review — it takes days and can be declined.
  2. Apply to each merchant you care about. The feed only ever contains advertisers you have an approved partnership with, so a new account returns nothing even when everything is set up correctly.
  3. In the Developer Portal → Account → Applications, create an API credential and copy the Client ID and Client Secret. Your SID is at the top right of the publisher dashboard.
  4. Put all three in a .env file next to server.js as COUPON_CLIENT_ID, COUPON_CLIENT_SECRET and COUPON_SCOPE_ID, then restart. The app handles the token exchange and refresh itself.

Worth knowing before you start: even fully configured, this covers only your partnered merchants — not "any store". For everyday shopping a browser extension at checkout will beat it. What this tab is actually good for is the tracker below: your own record of what really worked.
